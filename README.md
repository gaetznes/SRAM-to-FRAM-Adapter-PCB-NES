# SRAM-to-FRAM-Adapter-NES
Replaces battery backed up sram with fram

I built this to work on a SxROM pcb. Regardless if the original board used narrow or wide sram.

So far i've fit previous versions of it onto a SAROM & SNROM. First revision has been on my Dragon Warrior 1 since 2023 without issue.

Remember to remove the battery & sram before installing the adapter board.

You will also need 2.54 pitch row male pins, 74ls04 and FM1608 for this project

This revision has not been tested . It has been ordered and will be tested and updated.
